Important FAQ

What is DOM?
DOM means Document Object Model. It helps us to connect our HTML to our JS and make our website functional. We can do many types of fun things using DOM in our HTML
How do you select an element from DOM?
We can select elements from DOM in many ways some of these are:
  • getElementById
  • getElementsByTagName
  • getElementsByClassName
  • querySelector
What is event delegation in the context of the DOM, and why is it useful?
Instead of adding a click listener to every child, you put one on the parent and let events bubble up. It's faster, uses less memory, and works for elements added later.
How do you manipulate an element's attributes and styles using DOM?
For attributes, you use getAttribute, setAttribute, and removeAttribute. For styles, you use the style property like element.style.color = 'red', or you can add/remove classes with classList.add, classList.remove
